## Settled decisions

- **Keyless & private.** No API key ships in the app. In-app conversational planning was
  built, then removed for security; the Mac-mini + Tailscale bridge replaced it. Not
  reopened without the user.
- **Planning is conversational; execution is the app.** Recipe and plan *generation* lives
  in the Claude skills; the app assembles from the library and never authors it.
- **Sync is one-way pull + a feedback push.** Live two-way sync (ROADMAP #8) is explicitly
  deferred and out of scope for every current wave.
- **Design system is "Sage", dark-first, borderless hairline rows** (`DESIGN-SYSTEM.md`).
  Settled — extend it, don't revisit it.
- **Execution is sequential** (README §Execution model): `seed.json`, the running server,
  and the shared markdown library are global mutable state.
