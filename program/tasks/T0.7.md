## Why this task exists

`app/index.html` is 154,642 bytes. 129,150 is the generated inline `SEED`; of the 25,492 left,
**23,531 — 92% — is CSS in three inline `<style>` blocks**, and there is no `.css` file
anywhere in the repo. Nothing about that CSS can be reviewed, diffed or reasoned about
independently, and every regeneration of the seed touches the same file.

**This task moves bytes and changes nothing else.** That constraint is the point: it makes the
move provable, and it is what lets T0.8 delete the dead token set afterwards with confidence.
Resist every temptation to fix something you see on the way. Write it down and file it.

## The current shape, already measured — do not re-derive

| block | lines | what it is |
|---|---|---|
| 1 | 16–153 | old "Spiced Linen" tokens (31 `:root` + 29 dark) **plus 125 live base selectors** |
| 2 | 154–306 | the "Sage" design system — redefines `:root` from scratch, 63 selectors |
| 3 | 307–315 | 5 selectors of safe-area and typography patches |

Only **three** selectors are restyled in both 1 and 2: `.card`, `.sheet`, and
`.fld input,.fld select,.fld textarea`. Those are your collision points; everything else is
additive between blocks.

## In scope

Split into files under `app/styles/`, preserving cascade order exactly:

```
tokens.css       both token sets, still in order, still both present  ← T0.8 deletes one
base.css         block 1's reset, layout primitives, utilities
components.css   rows, chips, cards, nav, sheet, modal, toast
screens.css      per-screen rules + block 3's patch layer
```

Then: `<link>` them from `index.html` in that order, delete the three `<style>` blocks, add
every new file to `sw.js`'s `ASSETS`, **bump `const CACHE`**, and extend `scripts/pre-commit`
to cover `app/styles/*.css` the same way T0.2 extended it to `app/js/*.js`.

Where a rule's home is genuinely ambiguous, keep cascade order over tidiness. **Order is
correctness here**; the file boundary is only bookkeeping.

## Out of scope

- **Deleting anything.** The 29 dead tokens stay in `tokens.css` until T0.8. So do all 20
  `!important` declarations.
- Renaming selectors, reformatting, minifying, or "while I'm here" cleanups. A diff that is
  not obviously a move is a diff nobody can review.
- The Google-Fonts dependency (T0.12) and the directory move to `client/` (T0.11).

## How to prove it

"Looks the same" is one comparator and CONTRACT §4 rejects it. Do this instead:

1. Serve the app **before** the change and snapshot `getComputedStyle` for a fixed element set
   across every screen — Plan, Recipes, List, Cook, More — **in both themes** (the app defaults
   to `data-theme="dark"`; the light path is easy to forget).
2. Repeat after. **Diff the two snapshots: the correct result is empty.**
3. Second comparator: a screenshot pair per screen, and a clean console (a clean load emits
   zero messages — `knowledge/instruments.md`).

Save the snapshot script; T0.8 needs exactly the same instrument, and reusing it is most of
what makes T0.8 cheap.

## Known traps

- **Certify the server before measuring** — a listening port is not a working one (CONTRACT
  §3). This project has already lost three days to that.
- **Bump `const CACHE`.** New precached files plus an unbumped cache means installed phones
  keep the old inline CSS *and* fetch nothing new — permanently. This is the failure mode the
  whole program keeps paying for.
- Three files must stay in agreement: `app/styles/` on disk, the `<link>` tags, and `sw.js`'s
  `ASSETS`. They agree today for JS (16/16/16) by hand alone. T0.4's suite asserts this if it
  has landed; if it has not, check by hand and say you did.
- `embed_seed.py` rewrites `index.html` with a regex on `const SEED = {...};`. Confirm your
  edited `<head>` still survives a round-trip — run `build_seed.py && embed_seed.py` and
  re-diff. A `<link>` tag lost to the embed step would be invisible until a fresh install.
- Do not build the seed into `app/` on a live server (GOTCHAS 2026-08-04).

## Done when

`app/index.html` contains no `<style>` block, the computed-style diff across five screens × two
themes is empty, `CACHE` is bumped, `pre-commit` refuses a `app/styles/*.css` change without a
bump (demonstrated, not asserted), and `findings/T0.7.md` per CONTRACT §6 names which of §1's
four denominators it verified on.
