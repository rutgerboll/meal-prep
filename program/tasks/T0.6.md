## Start from what is already measured

`knowledge/structure-proposal.md` carries T0.1's receipts and a proposed layout. Read it first
and do not re-derive it. In brief, it establishes:

- `app/index.html` is 92% CSS by non-generated bytes (23,531 of 25,492), in three inline
  `<style>` blocks, with **no `.css` file anywhere in the repo**.
- Those blocks ship **two conflicting token sets**. Block 1 declares 31 `:root` tokens; **29
  are dead**, overridden by block 2's Sage tokens. `--pr` is terracotta where a reader looks
  and green where it wins. 20 `!important` declarations hold it together.
- Block 1's *base styles* (125 selectors) are live — only its *token layer* is dead. A cleanup
  must separate the two; deleting the block wholesale breaks the app.
- Two design-system documents both claim authority; the stale one (`design/design-system.md`,
  383 lines, June) is the one that says *"source of truth for the engineer."*
- 202 top-level JS globals across 16 files, with the file list hand-maintained in three places.
- `build_seed.py` is 1,096 lines but **coherent** — a parser suite with real seams. The
  proposal explicitly argues against splitting it. Agree or disagree with evidence; do not
  split it just because it is the biggest file.

## Known traps

- **`deploy.sh` cannot currently run** (T0.2), so there is no rehearsed rollback if a move
  breaks the mini. Any sequencing you recommend has to account for that; the proposal puts
  T0.2 first for exactly this reason.
- **Bump `const CACHE`** in any recommendation that touches `index.html` or `app/js/*.js`, and
  say so in the plan — installed phones stay stale otherwise, permanently.
- Do not treat "202 globals" as automatically bad. Establish whether it has actually caused a
  collision or a bug; a number is not a defect. Same for file size.
- The user's phrasing was tentative ("half-remembers", "I think — can't remember"). Do not
  manufacture a refactor to justify the task. "Here is the one thing worth doing and here is
  why the rest is fine" is the better outcome if that is what the evidence says.
