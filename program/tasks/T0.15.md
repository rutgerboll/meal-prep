# T0.15 — Review next dinner drafts in the app

Outcome: A dated plan and matching shopping list can sync into the PWA for review without replacing the active Cook and Grocery plan. Future agents can use the same project-owned files.

Inputs: `meal-plans/<id>.md` with `draft: true`, matching `grocery-lists/<id>.md`, and the existing recipe library.

Files in scope: `app/build_seed.py`, `app/meal-server.py`, `app/js/db.js`, `app/js/screen-plan.js`, `app/js/helpers-render.js`, `app/sw.js`, generated inline bootstrap seed, and the matching library files.

Check: In an isolated app/server, the draft and shopping lines appear on the Plan tab, the prior final plan remains active for Cook and Grocery, and changing `draft: true` to `draft: false` makes the newer plan active in the generated sync bundle. Check the running `/sync.json` path and JavaScript errors. Then verify the live server and distinguish it from an installed phone.
