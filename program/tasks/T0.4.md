# T0.4 — Add an app smoke suite

**Status:** open · **Origin:** expanded from the 2026-08-04 codebase-health task.
The old brief mixed a useful test suite with Kit's orchestration configuration.
Kit was retired; the suite remains valuable on its own.

## Why

The repo had no executable test suite when T0.1 reviewed it. Past defects
included a server that held its port while returning 404/500, an inline
bootstrap seed that drifted from the library, and a stale-code guard that
missed JavaScript edits. A focused suite should catch real regressions without
introducing a package manager or disturbing the live app.

## Scope

Add one documented command that runs useful checks from this repo and a fresh
worktree. Favor checks for the seed pipeline, bootstrap versus fresh seed,
service-worker asset list, and server health on a spare port. Choose only
checks that can run safely with current data and explain any omitted check.

Build seed output in a temporary location. Set `MP_BASE_DIR` to the actual
meal library. Start any test server on its own port and stop that PID only.
Treat a failing check as evidence; do not weaken it merely to obtain green.

## Done when

The command runs on both the main checkout and an isolated worktree, its scope
and result are recorded in `program/findings/T0.4.md`, and `program/TASKS.md`
is updated. Configure no Kit task orchestration.
